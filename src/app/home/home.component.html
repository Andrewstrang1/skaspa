Component Guide

1. DataTableH Component

The DataTableH component is a versatile and dynamic data table that supports:

  • Sorting and pagination
  • Selectable rows with bulk actions
  • Custom action buttons configured in the parent feature
  • Optional columns, like ratings or custom fields
  • Search and filter capabilities

Usage in a Feature Page

To use DataTableH in a feature component:

  1. Import the DataTableHComponent and include it in your feature’s HTML.
  2. Define the data structure with an interface (e.g., TableRow) for column names and types.
  3. Configure component inputs like data, displayedColumns, actionButtons, and tableTitle.
  4. Add methods for handling actions, such as editing or deleting rows.

Example

<app-data-table-h
    [data]="tableData"
    [displayedColumns]="displayedColumns"
    [selectable]="selectable"
    [actionButtons]="actionButtons"
    [showRating]="true"
    [tableTitle]="'Product Table'"
    (save)="handleSave($event)"
  ></app-data-table-h>

Customizing Columns

  • Dynamic Columns: Control displayed columns with displayedColumns in the feature component.
  • Rating Column: Add a rating column by setting [showRating]="true".

Configuring Actions

Define custom actions for row-level or bulk actions via actionButtons. Each button can open a modal, perform inline actions, or require confirmation:

actionButtons: ActionButton[] = [
    {{ '{' }}
      label: 'Edit',
      iconPath: 'M3 12l18 12-18 12',
      handler: (row) => this.editRow(row),
      location: 'row',
      modal: true,
      emitOnSave: true
    {{ '}' }},
    {{ '{' }}
      label: 'Delete Selected',
      iconPath: 'M3 6h18v2H3V6zM3 10h18v10H3V10z',
      handler: (_, selectedRows) => this.deleteSelectedRows(selectedRows),
      location: 'actionBar',
      requiresSelection: true,
      requiresConfirmation: true
      {{ '}' }}
  ];

2. StarRating Component

The StarRating component visually displays ratings with an optional review count and an interactive mode for user input.

Usage in a Feature Page

  1. Import and include StarRatingComponent in the feature component’s HTML where the rating should appear.
  2. Bind rating to display or capture the value, and set [interactive] to enable click-based rating.

Example

<app-star-rating 
    [(rating)]="userRating"
    [interactive]="true"
    [reviewCount]="100"
  ></app-star-rating>

Interactive Ratings and Submitting a Review

  • With interactive enabled, users click stars to set a rating, which emits a value to the feature for processing.
  • Combine with a textarea to capture additional review details.

Example with Review Submission

<app-star-rating [(rating)]="userRating" [interactive]="true"></app-star-rating>
  <textarea [(ngModel)]="userReview" placeholder="Write your review..."></textarea>
  <button (click)="submitReview()">Submit Review</button>
  
submitReview() {{ '{' }}
    console.log("User's Rating:", this.userRating);
    console.log("User's Review:", this.userReview);
  {{ '}' }}

These components are designed to be reusable and configurable for different feature pages. By following these guidelines, you can easily configure DataTableH and StarRating for your specific feature needs.
